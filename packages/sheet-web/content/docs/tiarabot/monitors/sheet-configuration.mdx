---
title: Sheet configuration moved to SheetWeb
description: Find the SheetWeb guide for managing TiaraBot's sheet mappings.
---

Sheet mapping configuration now has its own [SheetWeb guide](/docs/sheetweb/sheet-configuration).
Use that guide for the browser editor, draft lifecycle, range mapping, review, and activation.

TiaraBot still uses the active sheet configuration for schedule-backed operations. The bot's
Discord commands and server operations remain documented in the [TiaraBot command reference](/docs/tiarabot/command-reference).
