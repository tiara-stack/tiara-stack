SheetWeb is the browser dashboard for viewing a server's schedule and managing the configuration
that supports TiaraBot. It is separate from TiaraBot's Discord commands: use the dashboard for
browser-based schedule and configuration work, and use the TiaraBot guides for Discord operations.

<Callout title="Choose the right surface">
  SheetWeb shows and manages dashboard state. TiaraBot reads the active configuration and runs
  schedule, check-in, room, slot, and notification workflows in Discord.
</Callout>

## What belongs in SheetWeb

- Viewing a server's daily or calendar schedule.
- Switching between servers and schedule channels.
- Managing server settings, channels, and sheet mappings when your permissions allow it.
- Managing your own notification preferences.

## What belongs in TiaraBot

Use the [TiaraBot operating guide](/docs/tiarabot) for check-ins, room order, open slots, team
submissions, server commands, and bot-delivered updates.
