---
title: Navigate SheetWeb
description: Switch servers, move between schedule and administration, and find personal settings.
---

SheetWeb keeps schedule navigation separate from server administration. The active server remains
visible while you move between its schedule and settings.

## Open a server

1. Open **Dashboard** and choose **Servers**.
2. Select a server from the server list.
3. Use the server rail to switch quickly between servers. Hover or focus a server icon to see its
   full name.
4. Use the named server chooser beside the active server name when you want to search by reading
   the server names in a list.

The **Back to server list** button returns to the full server chooser. It is useful when the rail is
collapsed or when you want to reconsider which server to open.

## Read a schedule

Choose **Schedule** in the active server header, then select a schedule channel if the server has
more than one. The schedule surface provides:

- **Daily schedule** for the current day and nearby days.
- **Calendar** for moving to another date and seeing which days have scheduled entries.
- A channel-specific URL so opening a schedule does not lose the selected server or channel.

Date and view state may appear in the URL, but the main surface is represented by its path. Daily,
calendar, and server settings pages are separate destinations and can be bookmarked independently.

## How schedule hours map to time

Schedule hours are one-based and global across the full event. Schedule Hour 1 begins at the
**event start**, and Schedule Hour 82 begins 81 elapsed hours later. The **day** number only
identifies the schedule sheet; it is not an additional time offset.

Some existing workspaces are configured from a **chapter start** instead of the full event start.
That reference includes the chapter's event-wide first hour. For example, a chapter starting on
September 9 at 03:00 UTC at hour 49 means hour 49 is at that timestamp, hour 50 is one hour later,
and hour 82 is on September 10 at 12:00 UTC. SheetWeb keeps that established reference stable when
rows are added, removed, hidden, or reordered; it does not infer the event clock from whichever row
happens to appear first.

## Manage a server

Open **Server settings** from the active server header. This is where server-level administration
lives:

- **Server settings** manages the server configuration and monitor roles.
- **Channels** manages channel mappings and channel-related operations.
- **Sheet mappings** manages the browser-based sheet configuration editor.

These controls require the permissions shown by the page. If you can operate a channel but cannot
see server configuration, continue with the available channel tools or ask a server administrator.

## Manage personal settings

Open your account menu and choose **My preferences**, or open **Settings → Notifications**. These
settings belong to your account rather than a server, so they stay outside the server navigation.

## If a server or schedule is missing

Check that you are signed in with the Discord account that belongs to the server. A server can also
be unavailable when its schedule channel has not been configured or when your Discord permissions
do not allow SheetWeb to read it. Contact the server's mana/moni for server-specific access or
configuration help.
